A lightweight, cross-platform GUI text editor written in Pascal using the Lazarus IDE.

## Features
 
- Dark mode
- Syntax highlighting for Pascal and C
- Find and replace
- Toggleable line numbers
- Open terminal in the current file's directory
## Platform Support
 
| Platform       | Architecture | Status  |
|----------------|--------------|---------|
| Linux          | x86\_64      | ✅      |
| macOS          | aarch64      | ✅      |
| FreeBSD        | x86\_64      | ✅      |
| Haiku          | x86\_64      | ✅      |
| Windows        | x86\_64      | Planned |
 
## Building from Source
 
Open the `.lpi` project file in [Lazarus](https://www.lazarus-ide.org/) and compile. No external dependencies beyond the Lazarus component set are required.
